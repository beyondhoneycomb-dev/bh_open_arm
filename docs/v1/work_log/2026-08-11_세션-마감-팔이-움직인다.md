## 이 세션에서 내가 틀렸다가 정정한 것 셋

기록해 두는 이유: 같은 함정에 다음 사람도 빠진다.

1. **충돌 래치가 "실기 붙는 순간 터진다"** → 아니다. 가드 폴링은 `send_action` 안에서만 일어나고
   `torque_session`·`rig_session` 은 그것을 안 부른다. 데이터 수집·추론 경로가 살아날 때 걸린다.
2. **바인딩이 유효하다** (`check_binding` 이 `ok=True` 니까) → 그 초록은 **손으로 적어 넣은
   것**이었다. `can_binding.json` 에는 타임스탬프도 방법도 근거도 없어 파일 혼자서는 측정값과
   기입값을 구별 못 한다. **초록이 어떻게 초록이 됐는지를 물었어야 했다.**
   (좌우 자체는 별개 근거로 해소됐다 — `dev_id` 축이 안 바뀌었고 케이블도 안 뽑혔다.)
3. **정지마찰 0.73 N·m 실측** → 팔이 걸려 있었다. 풀린 뒤 같은 관절이 0.08 — **9배 차이**.
   `τ = kp·Δq` 는 모터가 **무엇에 막혀 있든** 성립한다. 멎은 자리의 토크는 **저항의 합**이지
   마찰이 아니다.

셋 다 같은 뿌리다 — **문서나 초록 신호를 읽고 그것이 어떻게 만들어졌는지 안 물었다.**

## 이 세션 최대의 낭비

같은 리그에서 이미 답한 질문이다. 읽은 뒤 반나절 만에 코어에 껍데기 셋을 붙여 팔이 움직였다.

# 2026-08-05 — 양팔 드롭 카운트가 정확히 두 배였다

## Context

앞 세션이 핸드오프에 이렇게 적었다:

> 양팔의 `DropCounter` 가 프로세스 전역 Damiao 로거 하나에 각자 핸들러를 붙이므로,
> 한쪽 채널의 드롭이 반대쪽 팔의 읽기를 실패로 표시한다(`bus_writer.py:351`). 방향은 안전한 쪽이라 급하지 않다.

이 세션에서 그 주장을 검증하다가 **기계는 맞고 결과는 틀렸다**는 것이 나왔다.
읽기 실패가 아니라 텔레메트리 2배였고, 그쪽이 훨씬 나쁘다.

`can_packet_drop_count`는 `01` FR-SYS-018상 **모터 피드백 프레임이 유실됐다는 유일한 증거**다.
벤더 버스는 드롭을 로그로만 남기고 마지막 상태를 재사용하므로, 이 숫자가 없으면
손실 많은 버스로 기록한 에피소드와 깨끗한 에피소드를 구분할 방법이 없다.

## Files changed

- `packages/lerobot_robot_openarm/openarm_follower_oa.py`
  - `BiOaOpenArmFollower.__init__` — `DropCounter` 하나를 만들어 양팔에 넘긴다.

## Why

**기계.** `logging.getLogger(name)`은 프로세스 전역 싱글턴이다.

```
openarm_follower_oa.py:355   self._drop_counter = drop_counter if ... else DropCounter()
openarm_follower_oa.py:1200  return OaOpenArmFollower(arm_config, publisher=publisher)  ← 안 넘김
openarm_follower_oa.py:512   self._drop_counter.attach()                                ← 프로덕션
bus_writer.py:378            logging.getLogger(self._logger_name).addHandler(self._handler)
```

양팔이 각자 `DropCounter()`를 만들고 각자 핸들러를 **같은 로거 하나**에 붙인다.
어느 쪽 버스에서 드롭이 나든 핸들러 둘 다 울리므로 **각 카운터가 이미 양팔 합계**다.
그것을 `:1283`이 또 더했다. 동시성이 필요 없고 항상 2배다.

옛 docstring이 틀린 전제를 적어놨다 — *"두 팔은 버스 락 하나와 카운터 의미 하나를 공유하므로
로봇의 합계는 그 둘의 합"*. 공유하는 것은 **락이 아니라 로거**이고, 그래서 각 값이 이미 합계다.

**왜 팔별 귀속을 살리지 않았나.** 벤더가 모듈 로거 하나에만 쓰므로 로거로는 원리상 팔을 구분할 수
없다. 그러니 정직한 모델은 "이 프로세스의 드롭 총계 하나"이고, 그것을 타입에 박는 방법이
**양팔이 객체 하나를 공유하는 것**이다. `OaOpenArmFollower.__init__`은 이미 `drop_counter`
인자를 받고 있었고(`:312`), 양팔 쪽만 안 넘기고 있었다.

**같은 객체를 두 번 `attach` 해도 안전한가.** CPython `Logger.addHandler`가
`if not (hdlr in self.handlers)`로 동일 핸들러를 한 번만 받고, `removeHandler`도 없으면 무동작이다.
소스를 직접 읽어 확인했다.

**`max`인 이유.** 공유 카운터에서는 두 값이 같으니 `max`는 그 값이다. 픽스처가 팔을 주입해
각자 카운터를 들고 오는 경우에도, 나중에 attach 된 카운터는 **더 적게 봤을 뿐 더 많이 볼 수는
없으므로** `max`가 맞다. `sum`은 일어나지 않은 드롭을 보고한다.

**앞 세션이 왜 놓쳤나.** 공유는 정확히 봤는데 소비 지점을 안 열었다. `bus_read_ok`는
`:1043`에서 재샘플하고 `:1058`에서 비교하는 **델타**라 순차 동작에서 흡수된다 — 그래서
"반대쪽 읽기 실패"는 지금 안 일어난다. 진짜 결과는 그 옆의 `get_observation` 합산이었다.
**공유를 발견하는 것과 그 공유가 무엇을 망가뜨리는지 아는 것은 다른 일이다.**
